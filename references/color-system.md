# 极简资讯手绘配色系统

白色背景和深色线条不计入颜色。每张图默认只用 2–3 个核心色；第 4 色只在确有语义必要时使用。颜色不是填满画面的装饰，而是帮助读者先锁定中心、再识别风险或角色。

## 基础颜色

- 橙杏 `#FFA056`：中心圆、主符号、核心对象、主命题。
- 鲜红 `#E22616`：风险、否定、警示、关键提问、重点框。
- 靛蓝 `#5B57A6`：人物衣物、系统状态、第二层对象。
- 路牌绿 `#16A56B`：方向、通过、状态正常；仅在语义需要时使用。
- 小鸽钉雾蓝 `#AFC7DC`：固定 IP 主体色；包含小鸽钉时不得换成靛紫、深蓝、暖米杏或灰白。
- 小鸽钉挎包芥黄 `#F4BF3A`：固定 IP 识别色，只用于斜挎包及其小扣件。
- 肤色/浅棕：仅用于简笔人物的脸和手，不作为额外强调色。

## 用法

- 先用一个大而干净的主色色块建立中心锚点，通常是一个圆形、三角形、色块物件或一件衣物。
- 让红色只承担真正的警示和问题；让蓝色只承担人物/第二层信息；绿色仅作为“方向/正常”的稀有信号。
- 每个卫星最多一块主色或一处彩色轮廓；不为所有物件填色。
- 总彩色面积控制在画面约 15%–30%，并保留大量纯白。

## 禁止

- 不要渐变、阴影、高光、半透明玻璃、3D 反光、金属材质或彩色排线。
- 不要把橙、红、蓝、绿平均撒满画面；若三个以上颜色同样抢眼，删去一个。
- 不要低饱和灰泥色、荧光色或复杂配色；颜色应干净、明快但不刺眼。
